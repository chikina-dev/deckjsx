# v0.8.1 Cleanup Review

Historical note: this review predates the hardened public authoring type surface. In current
authoring diagnostics, rejected props, style keys, and style values should be described as "not part
of the public authoring API". The word "unsupported" in this document refers to historical review
language or projection fallback records, not the preferred wording for public authoring errors.

v0.8.1 narrows the pre-1.0 public surface after the direct PPTX writer migration and prepares the
internal pipeline for HMR-oriented invalidation boundaries.

## Public Surface

- Removed the public PPTX `compression` render option and `PptxCompressionMode` type.
- Removed Direct Style Props from JSX intrinsic props and Slide Declaration options.
- Kept authoring appearance input in `style`, StyleSheets, Theme Defaults, and Template Area
  relationships.
- Kept Layout Input Snapshot and Projected Layout Snapshot internal; they are not public inspection
  artifacts in v0.8.1.

## Internal Cleanup

- Removed the legacy AuthorNode representation and `deckjsx.author-node` runtime marker from source.
- Added a Layout Input Snapshot boundary between Semantic Author Graph/resolved styles and Projected
  Layout Snapshot.
- Moved broad normalization ownership out of `compiler/normalization` into layout-owned
  normalization.
- Switched the direct PPTX ZIP emitter to deckjsx-owned store-only ZIP32 output using CRC32, fixed
  headers, deterministic metadata, and platform `TextEncoder`.
- Removed the runtime `fflate` dependency.

## Validation Focus

- `vp check`
- `vp test`
- public-surface guards for declarations, dependencies, removed compression vocabulary, removed
  AuthorNode marker, and hidden layout snapshot types
- focused non-public authoring prop diagnostics tests
- store-only ZIP structure tests

## Known Scope Boundaries

- v0.8.1 does not add public HMR APIs.
- v0.8.1 does not expose public layout snapshot inspection APIs.
- v0.8.1 does not add DEFLATE, ZIP64, or public ZIP writer configuration.
- v0.8.1 does not add PDF projection or full CSS layout parity.
